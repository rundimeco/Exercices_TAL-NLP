Pour introduire le cours, Utilisez les données de TD00_data.zip :

- vous avez un fichier reference.json (vérité de terrain)
- un dossier par type de tâche 
- dans chacun de ce dossier, des fichiers de résultats pour différents systèmes
- évaluer chacun des systèmes avec les mesures connues : accuracy/exactitude, précision/rappel/f-mesure.... ou d'autres si besoin
- classer les systèmes par ordre décroissant de performance pour chaque mesure
